# Introduction to Computer Games

컴퓨터 게임 입문 수업의 실습 프로젝트와 자료를 모아두는 저장소입니다.
각 실습(Lab)은 독립된 하위 폴더로 구성되며, 폴더마다 자체 README와 소스 코드를 포함합니다.

## 저장소 구조

```
Introduction-to-Computer-Games/
├── README.md                     # 이 파일
└── Vibe Coding Lab/              # 바이브 코딩 실습 모음
    └── KiroGhost/                # Processing - 'Kiro의 유령' 캐릭터 렌더링
        ├── KiroGhost.pde         # Processing 스케치 (메인)
        └── README.md             # 실습 설명 및 실행 방법
```

## 실습 목록

| 실습 | 폴더 | 언어/도구 | 설명 |
|------|------|-----------|------|
| Vibe Coding Lab 01 | `Vibe Coding Lab/KiroGhost` | Processing | 'Kiro의 유령' 캐릭터를 화면에 렌더링하고 애니메이션 적용 |

## 환경

- [Processing](https://processing.org/) 4.x (Java 모드)
